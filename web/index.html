Эон:

// Как играть //

  • Цель: открыть все безопасные клетки кибер-сетки, не подорвавшись на плазменных минах.
  • Число на клетке — количество мин в соседних 8 клетках.

Управление (ПК)

  • ЛКМ — открыть клетку.
  • ПКМ — цикл: флаг → вопрос → пусто.
  • СКМ или двойной клик по числу — аккорд: если вокруг числа стоит столько флагов, каково число, соседние клетки открываются.
  • Удержание ЛКМ на числе — «разведка»: подсветка соседей без открытия.
  • Esc — пауза.

Управление (мобильные)

  • Тап — открыть клетку.
  • Долгое нажатие (≈0.45 с) — флаг/вопрос.
  • Двойной тап по числу — аккорд.
  • Удержание на числе — разведка соседей.
  • Камера: перетаскивание — вращение, щипок/колесо — масштаб.

Кампания

  • 100 секторов, три эона сложности. С каждым уровнем сетка растёт, а плотность мин увеличивается. Все поля построены детерминированным алгоритмом по единому зерну и проверены решаемыми без угадывания.
  • Стартовая зона каждого поля гарантированно открыта и безопасна.
